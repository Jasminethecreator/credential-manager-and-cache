# Credential Manager and Cache Management

## Objective

Manage stored Windows credentials and clear cached browser data as troubleshooting steps for authentication and account sign-in issues.

## Tools & Environment

* Windows 11
* Windows Credential Manager
* Microsoft Edge
* Control Panel
* Microsoft Azure virtual machine

## Steps Performed

1. Opened **Credential Manager** through Windows Control Panel.
2. Reviewed stored **Generic Credentials** associated with the user account.
3. Removed stored credentials as part of account lockout troubleshooting.
4. Opened the browser's **Delete browsing data** settings.
5. Set the time range to **All time**.
6. Selected **Cached images and files**.
7. Cleared the selected cached browser data as an additional troubleshooting step.
